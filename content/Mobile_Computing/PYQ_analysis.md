## 🔥 Most Repeated Questions

### 2021 (ASSIGNMENT format — answer any 2 × 20 marks)
1. GSM functional architecture diagram + applications + limitations of MC
2. Characteristics of SDMA, TDMA, FDMA, CDMA + Hidden/Exposed terminals
3. IP packet transfer from fixed node to mobile node (with diagram) + TCP congestion control
4. Short notes: Goals of Mobile IP | DHCP | Handoff types | MC vs Wireless

### 2022 (Group A+B+C format — 5+15+20)
**Group A (1 mark):** GSM expand, protocol in MC, SDMA expand, Mobile TCP, snooping, hoarding, selective tuning, context-free computing  
**Group B (5 mark):** MC limitations, MAC layer functions, MAC techniques, Mobile IP entities, GSM handover reasons  
**Group C (10 mark):** Mobile TCP operation + compare traditional/mobile TCP | Mobile OS | DHCP with state chart | Short notes (Transaction TCP, Tunneling)
