## 🔥 Most Repeated Questions

### Numerical Questions (10 marks — appeared BOTH years)
1. **Solve LPP by Simplex Method** — maximize/minimize with constraints
2. **Transportation Problem by Vogel's Approximation (VAM)** + optimal solution
3. **Assignment Problem using Hungarian Method** — minimize cost/time
4. **PERT/CPM: Find Critical Path** — given activity table with to/tm/tp

### Theory Questions (5 marks — appeared both years)
1. **Graphical method** — solve LP problem graphically
2. **Write the Dual of LPP** — convert primal to dual
3. **Degeneracy in LPP** — definition + how to resolve
4. **Feasible solution, unbounded solution** — definitions

### 1-mark Questions (appeared both years)
- What is feasible solution?
- What is objective function?
- What is optimum solution?
- Why duality is used?
- What is CPM/PERT?
